    Option and Result

    Option[T] represents a present or absent value. Result[T] contains either a successful value or an exception.

    Option

    fpstreams.Option dataclass

    Bases: Generic[T]

    Store either one non-None value or an empty state.

    Instances are immutable and cannot distinguish a present None from absence. Use :meth:of, :meth:of_nullable, or :meth:empty to make that choice explicit.
